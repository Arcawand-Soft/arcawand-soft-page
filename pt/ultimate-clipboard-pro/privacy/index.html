Política de PrivacidadeUltimate Clipboard Pro

Ultimate Clipboard Pro foi projetado como uma extensão de navegador local. Esta página explica quais dados são tratados, onde ficam, quais serviços opcionais podem ser contatados e como os usuários permanecem no controle.

Última atualização: 13 de maio de 2026

Visão geral

Ultimate Clipboard Pro é uma extensão Chrome construída por ArcaWand Soft para ajudar os usuários a capturar, organizar, pesquisar, editar e reutilizar texto, código e imagens durante a navegação.

O produto foi projetado com uma filosofia local: o gerenciamento normal da captura ocorre dentro do ambiente de extensão do navegador no dispositivo do usuário.

Desenvolvedor e contato

Ultimate Clipboard Pro é publicado por ArcaWand Soft. Para questões de privacidade, suporte ou questões de conformidade da Web Store Chrome, entre em contato com contact@arcawand-soft.com.

Chrome Compromisso de dados do usuário da Web Store

Esta política destina-se a corresponder ao comportamento da extensão e às divulgações de privacidade fornecidas no Painel do desenvolvedor da Web Store Chrome. Se uma divulgação, permissão ou recurso for alterado, esta política deverá ser atualizada adequadamente.

A extensão usa as permissões solicitadas apenas para fornecer ou melhorar recursos do produto claramente descritos. Não usa permissões para coletar dados de navegação não relacionados.

Declaração de uso limitado da API do Google

Se o usuário ativar a sincronização Google Drive, a extensão poderá receber informações das APIs do Google para criar, ler, atualizar ou restaurar os arquivos de backup Ultimate Clipboard Pro do usuário.

O uso e a transferência de informações recebidas das APIs do Google obedecerão à Política de Dados do Usuário da Web Store Chrome, incluindo os requisitos de Uso Limitado. Os dados da API do Google são usados ​​apenas para fornecer recursos de backup e sincronização voltados para o usuário, não são vendidos e não são usados ​​para publicidade.

Categorias de dados detalhadas

O conteúdo fornecido pelo usuário pode incluir texto capturado, código, imagens, capturas de tela, notas, títulos escritos manualmente, categorias e conteúdo de montagem.

Os metadados de origem e uso podem incluir título da página, URL de origem, favicon, data de captura, data de criação da versão, favoritos, estado fixado, estado da lixeira, estado do cofre, preferências de exibição, idioma, tema, cor de destaque e outras configurações selecionadas pelo usuário.

O status da licença e do pagamento pode incluir as informações mínimas necessárias para verificar o acesso Pro por meio da licença ou provedor de pagamento selecionado. ArcaWand Soft não processa números de cartão dentro do ramal.

Finalidades do processamento

Os dados são processados para salvar capturas, exibi-las na extensão, organizá-las por espaço de trabalho e categoria, pesquisá-las, criar versões, restaurar capturas excluídas, copiar capturas de volta para a área de transferência, exportar backups, sincronizar backups opcionais do Drive e impor limites ou acesso Pro.

Compartilhamento e serviços de terceiros

O conteúdo capturado não é compartilhado com ArcaWand Soft para uso local normal.

Serviços opcionais de terceiros podem ser contatados apenas quando necessário: Google Drive para sincronização habilitada pelo usuário, provedores de pagamento ou licença para ativação de Pro e análises básicas do site para o site de marketing público.

Segurança e transmissão

Os dados das extensões locais permanecem no ambiente de extensões do navegador, a menos que o usuário os exporte, copie, ative a sincronização do Drive ou use outro recurso explícito que mova dados.

Quando a comunicação em rede for necessária para serviços opcionais, deverá utilizar HTTPS ou o transporte seguro fornecido pelo navegador e pelo fornecedor relevante.

Retenção, exclusão e controle de usuários

Os usuários podem excluir capturas dentro da extensão, esvaziar a lixeira quando disponível, exportar backups locais, restaurar backups, desconectar a sincronização do Drive e remover a extensão de Chrome.

Desinstalar a extensão ou limpar o armazenamento da extensão Chrome pode excluir dados locais. Os dados armazenados em Google Drive permanecem na conta do Google do usuário até que o usuário os exclua.

Crianças e conteúdo sensível

Ultimate Clipboard Pro é uma ferramenta de produtividade para usuários em geral e não é direcionada a crianças. Os usuários devem evitar armazenar segredos altamente confidenciais, a menos que compreendam seu próprio dispositivo, navegador e modelo de segurança de backup.

Uso internacional

A extensão e o site podem ser usados internacionalmente. Os prestadores de serviços opcionais poderão processar dados técnicos nos países onde operam, de acordo com os seus próprios termos e políticas de privacidade.

Atualizações de políticas

Esta política de privacidade pode ser atualizada para refletir alterações legais, de produto, da Chrome Web Store ou de fornecedor. A data mostrada nesta página indica a última atualização publicada.

Dados manipulados pela extensão

Dependendo dos recursos usados, a extensão pode armazenar texto capturado, código, dados de imagem, capturas de tela, metadados de páginas, títulos, notas, categorias, favoritos, estados fixados, URLs de origem, favicons, histórico de versões, preferências de exibição e configurações do usuário.

Armazenamento local

Por padrão, o conteúdo e as configurações capturados são armazenados localmente por meio do armazenamento de extensões do navegador. Remover a extensão ou limpar os dados da extensão do navegador pode remover capturas locais, a menos que o usuário tenha exportado ou sincronizado um backup.

Sincronização Google Drive opcional

Se o usuário conectar Google Drive, a extensão poderá criar ou atualizar uma pasta Ultimate Clipboard Pro na conta do usuário do Drive para fazer backup e restaurar os dados da extensão.

A sincronização Google Drive é opcional e controlada pelo usuário.

Pagamentos e licenciamento

Os fluxos de licenciamento e pagamento de Pro podem usar provedores terceirizados de pagamento e licença. Os detalhes de pagamento são gerenciados por esses provedores, não por um banco de dados de captura público ArcaWand Soft.

A extensão pode verificar o estado da licença para desbloquear a funcionalidade Pro.

Nenhuma venda de conteúdo capturado

ArcaWand Soft não vende conteúdo capturado da área de transferência. A extensão é destinada à produtividade privada, organização e reutilização por parte do usuário.

Permissões do navegador

A extensão solicita permissões necessárias para captura, armazenamento, área de transferência, interface e fluxos de trabalho de sincronização opcionais. Os usuários podem revisar as permissões de extensão em Chrome antes de instalar ou atualizar.

Backups e exportações

As exportações JSON ou ZIP locais são criadas a pedido do usuário e devem ser armazenadas com cuidado. Qualquer pessoa com acesso a um backup exportado poderá ler seu conteúdo.

Expectativas de segurança

Os usuários devem manter Chrome atualizado, proteger sua conta do sistema operacional, evitar extensões não confiáveis e armazenar backups em locais confiáveis. O acesso ao cofre reduz a exposição casual, mas não substitui a segurança do sistema operacional.

Contato

Para questões de privacidade, entre em contato com ArcaWand Soft em contact@arcawand-soft.com.
