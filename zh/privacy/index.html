隐私政策

ArcaWand Soft 网站如何处理技术数据、联系消息、启动通知、分析、外部服务和用户权限。

本政策的范围

本政策适用于 arcawand-soft.com 上的公共 ArcaWand Soft 网站，包括有关 ArcaWand Soft 的一般页面、公共产品演示页面、联系页面、发布公告和信息内容。

Pro管道特定页面可能有自己的隐私政策。本一般网站政策不描述任何产品或浏览器扩展的内部存储、权限或功能行为。

谁运营该网站

该网站由 ArcaWand Soft 运营。对于隐私问题、数据请求、支持问题或安全问题，请联系 contact@arcawand-soft.com。

您访问时处理的数据

该网站主要是一个静态信息网站，不需要访客帐户。托管、安全和性能系统可以自动处理技术数据，例如 IP 地址或大致位置、浏览器和设备详细信息、请求的 URL、引荐来源网址、语言首选项、访问日期和时间、错误信息和基本交互信号。

这些信息用于交付网站、保持网站可用、防止滥用、诊断错误、衡量性能、了解哪些页面有用以及提高内容质量。

联系留言

当您通过电子邮件或联系链接联系 ArcaWand Soft 时，我们会收到您选择发送的信息：电子邮件地址、姓名（如果提供）、消息内容、主题、附件和任何自愿的技术背景。

我们使用这些数据来响应、提供支持、管理业务或媒体询问、跟进产品反馈并在需要时保留合理的交流记录。

启动通知和电子邮件表单

某些页面可能会邀请访问者留下电子邮件地址，以便收到有关发布或重要更新的通知。当激活时，该地址仅用于规定的通知和直接相关的通信。

表单可能依赖于安全的服务器端端点或电子邮件服务。私有 API 密钥和提供商机密绝不会故意在公共网站代码中发布。您可以随时取消订阅或请求删除。

分析、cookie 和本地存储

该网站可能会使用注重隐私的分析、安全脚本、性能工具或错误诊断。根据配置，这些工具可能会使用 cookie、本地存储、请求元数据或类似的浏览器技术。

语言首选项、界面选择或关闭状态可能会本地存储在您的浏览器中，以便网站的行为保持一致。您可以从浏览器设置中清除 cookie 和网站数据。

托管和外部服务

该网站作为静态站点托管，可能使用托管、DNS、CDN、安全、分析、电子邮件传送、表单处理、支付链接和外部分发页面的基础设施服务。

这些提供商仅根据需要处理有限的数据，以提供服务、保护站点、路由消息、处理付款、衡量绩效或遵守法律义务。外部结帐页面、应用程序商店、Chrome 网络商店页面、社交平台和第三方链接均受其自己的隐私政策管辖。

目的和法律依据

根据您所在的位置，处理可能依赖于运营、保护和改进网站的合法利益、可选分析或营销传播所需的同意、响应直接请求时的合同必要性以及必须保存记录的法律义务。

数据共享

ArcaWand Soft 不会出售通过网站收集的个人数据。有限的数据可能会与帮助托管、保护、分析、操作或通过网站进行通信的服务提供商共享，或者在法律合规、安全、欺诈预防或合法法律要求需要时共享。

保留率

技术日志仅保留安全、调试、分析和操作可靠性所需的合理期限。只要需要回答请求、维护业务记录和保护合法利益，联系电子邮件就会被保留。通知注册数据将一直保留到取消订阅、删除请求或服务清理为止。

安全性

该网站使用 HTTPS 和信誉良好的基础设施提供商。没有公共网站可以保证绝对的安全，但网站应尽可能保持简单和静态，避免不必要的数据收集，并避免在前端代码中暴露私人凭据。

您的权利

根据您所在的国家或地区，您可能有权访问、更正、删除、限制或反对处理、撤回同意、请求可移植性或向数据保护机构提出投诉。

要行使这些权利，请联系 contact@arcawand-soft.com。我们可能需要足够的信息来验证和处理请求。

儿童

该网站不针对儿童，也不会故意要求儿童提供个人数据。如果您认为儿童通过该网站提供了个人数据，请联系我们，以便我们在适当的情况下进行审查和删除。

本政策的变更

当网站、法律要求、服务提供商或隐私惯例发生变化时，本政策可能会更新。本页发布的最新版本自发布之日起适用。
