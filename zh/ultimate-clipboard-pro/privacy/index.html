隐私政策Ultimate Clipboard Pro

Ultimate Clipboard Pro 被设计为本地优先的浏览器扩展。此页面解释了处理哪些数据、数据存放在哪里、可以联系哪些可选服务以及用户如何保持控制。

最后更新时间：2026 年 5 月 13 日

概述

Ultimate Clipboard Pro 是由 ArcaWand Soft 构建的 Chrome 扩展，可帮助用户在浏览时捕获、组织、搜索、编辑和重用文本、代码和图像。

该产品的设计遵循本地优先的理念：正常的捕获管理发生在用户设备上的浏览器扩展环境内。

开发商及联系方式

Ultimate Clipboard Pro 由 ArcaWand Soft 发布。有关隐私、支持或 Chrome 网上应用店合规性问题，请联系 contact@arcawand-soft.com。

Chrome 网上应用店用户数据承诺

此政策旨在匹配扩展程序的行为以及 Chrome Web Store 开发人员仪表板中提供的隐私披露。如果披露、许可或功能发生变化，本政策应相应更新。

该扩展程序仅使用请求的权限来提供或改进明确描述的产品功能。它不使用权限来收集不相关的浏览数据。

Google API 限制使用声明

如果用户启用 Google Drive 同步，则扩展程序可能会从 Google API 接收信息，以创建、读取、更新或恢复用户的 Ultimate Clipboard Pro 备份文件。

使用和传输从 Google API 收到的信息将遵守 Chrome 网上应用店用户数据政策，包括限制使用要求。 Google API 数据仅用于提供面向用户的备份和同步功能，不会出售，也不用于广告。

详细数据类别

用户提供的内容可以包括捕获的文本、代码、图像、屏幕截图、注释、手写标题、类别和蒙太奇内容。

源和使用元数据可以包括页面标题、源URL、图标、捕获日期、版本创建日期、收藏夹、固定状态、垃圾状态、保管库状态、显示首选项、语言、主题、强调色和用户选择的其他设置。

许可证和付款状态可能包括通过所选许可证或付款提供商验证 Pro 访问权限所需的最少信息。 ArcaWand Soft 不处理扩展内的卡号。

处理目的

处理数据以保存捕获、在扩展中显示它们、按工作区和类别组织它们、搜索它们、创建版本、恢复已删除的捕获、将捕获复制回剪贴板、导出备份、同步可选驱动器备份以及强制 Pro 限制或访问。

共享和第三方服务

捕获的内容不会与 ArcaWand Soft 共享以供正常本地使用。

仅在需要时才可以联系可选的第三方服务：Google Drive 用于用户启用的同步、支付或许可提供商用于 Pro 激活以及公共营销网站的基本网站分析。

安全与传输

本地扩展数据保留在浏览器扩展环境中，除非用户导出、复制、启用云端硬盘同步或使用其他移动数据的显式功能。

当可选服务需要网络通信时，应使用 HTTPS 或浏览器和相关提供商提供的安全传输。

保留、删除和用户控制

用户可以删除扩展程序内的捕获、清空可用的垃圾箱、导出本地备份、恢复备份、断开驱动器同步以及从 Chrome 中删除扩展程序。

卸载扩展或清除 Chrome 扩展存储可能会删除本地数据。存储在 Google Drive 中的数据保留在用户的 Google 帐户下，直到用户将其删除。

儿童和敏感内容

Ultimate Clipboard Pro 是面向一般用户的生产力工具，不针对儿童。用户应避免存储高度敏感的机密，除非他们了解自己的设备、浏览器和备份安全模型。

国际使用

该扩展程序和网站可在国际范围内使用。可选服务提供商可以根据自己的条款和隐私政策在其运营所在国家/地区处理技术数据。

政策更新

本隐私政策可能会更新，以反映产品、法律、Chrome 网络商店或提供商的变更。此页面上显示的日期表示最新发布的更新。

扩展处理的数据

根据所使用的功能，扩展程序可以存储捕获的文本、代码、图像数据、屏幕截图、页面元数据、标题、注释、类别、收藏夹、固定状态、源 URL、收藏夹图标、版本历史记录、显示首选项和用户设置。

本地存储

默认情况下，捕获的内容和设置通过浏览器扩展存储存储在本地。删除扩展或清除浏览器扩展数据可能会删除本地捕获，除非用户已导出或同步备份。

可选的 Google Drive 同步

如果用户连接 Google Drive，扩展程序可能会在用户云端硬盘帐户中创建或更新 Ultimate Clipboard Pro 文件夹以备份和恢复扩展程序数据。

Google Drive 同步是可选的，由用户控制。

付款和许可

Pro 许可和支付流程可以使用第三方支付和许可提供商。付款详细信息由这些提供商处理，而不是由公共 ArcaWand Soft 捕获数据库处理。

该扩展可以验证许可证状态以解锁 Pro 功能。

禁止出售捕获的内容

ArcaWand Soft 不出售捕获的剪贴板内容。该扩展旨在提高用户的私人生产力、组织和重用。

浏览器权限

该扩展请求捕获、存储、剪贴板、界面和可选同步工作流程所需的权限。在安装或更新之前，用户可以在 Chrome 中查看扩展权限。

备份和导出

本地 JSON 或 ZIP 导出是根据用户请求创建的，应小心存储。任何有权访问导出备份的人都可以读取其内容。

安全期望

用户应保持 Chrome 更新，保护其操作系统帐户，避免不受信任的扩展并将备份存储在受信任的位置。保管库访问可减少偶然暴露，但不会取代操作系统安全性。

联系方式

如有隐私问题，请通过 contact@arcawand-soft.com 联系 ArcaWand Soft。
