Cronologia locale e controllo dell'utente

Quando la cronologia è attiva, gli elementi ammissibili della conversazione sono conservati localmente dall'estensione sul dispositivo dell'Utente. L'Utente mantiene il controllo: può eliminare una conversazione specifica o l'intera cronologia dall'interfaccia dedicata.

Password e nessun accesso server

La cronologia è protetta da password locale e domanda segreta. La password non è destinata a essere inviata al server per lettura remota. In caso di dimenticanza o ripristino, l'eliminazione completa della cronologia locale è necessaria per evitare accessi non autorizzati.

Verifica di quote e crediti

Per applicare limiti Free, crediti regalati e diritti Plus/Pro, Figgliz può verificare lato server licenza, ID locale di installazione, IP o hash, fuso orario, token di azione e accettazioni. Questi controlli non archiviano il contenuto delle conversazioni sul server.
