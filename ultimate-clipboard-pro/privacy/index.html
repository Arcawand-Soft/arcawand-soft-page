Privacy policy

Ultimate Clipboard Pro is designed for private, user-controlled work. August 22, 2026

01Ultimate Clipboard Pro is designed for private, user-controlled work

Ultimate Clipboard Pro is designed for private, user-controlled work. It processes clipboard-related content only to provide requested features: deliberate capture, organization, local search, editing, copy-back, versioning, title management, backup, restore, optional Drive sync and Pro license validation.

02Regular extension data is stored in chrome

Regular extension data is stored in chrome.storage.local in the user's Chrome profile. Arcawand Soft does not operate a content collection server and does not receive copied content, images, screenshots, titles, notes, categories, searches, source history, Vault data, view preferences or settings.

03Data that may be stored locally includes deliberate text captures, code captures, image captures, page Markdown captures, screenshots, previews, titles, notes, version contents, categories, subcategories, favorites, pinned states, timestamps, source domains, source URLs, favicons, launcher position, view modes and user settings

Data that may be stored locally includes deliberate text captures, code captures, image captures, page Markdown captures, screenshots, previews, titles, notes, version contents, categories, subcategories, favorites, pinned states, timestamps, source domains, source URLs, favicons, launcher position, view modes and user settings.

04The extension does not sell, rent, trade, transfer or commercially exploit user content

The extension does not sell, rent, trade, transfer or commercially exploit user content. No account, password, name, phone number or identity profile is required for normal clipboard use.

05The extension contains no advertising, ad targeting, behavioral profiling or developer analytics

The extension contains no advertising, ad targeting, behavioral profiling or developer analytics. It does not send browsing analytics, search analytics, source timelines, backup logs or telemetry to Arcawand Soft.

06Chrome permissions are used only for visible product features

Chrome permissions are used only for visible product features: capture on supported pages, user-triggered clipboard reading and writing, local storage, context menus, extension views, active-tab actions, screenshots, local OCR, monitor-aware placement, local ZIP import/export, and Google identity and Drive file synchronization only when the user enables it.

07The user controls stored data

The user controls stored data. Items can be edited, titled, versioned, deleted, categorized, dragged, moved, protected in Vault, exported to a ZIP backup, restored from local files, synchronized to Drive when Pro is enabled, or removed by clearing extension storage.

08Dodo Payments acts as merchant of record for the Pro checkout and processes payment, applicable transaction taxes and payment documentation under its own terms

Dodo Payments acts as merchant of record for the Pro checkout and processes payment, applicable transaction taxes and payment documentation under its own terms. The extension communicates with the dedicated Arcawand Soft license service for license operations; that service verifies the commercial entitlement with Dodo. Neither flow receives captured content or Drive backups.

09Multi-device sharing occurs only through the Google Drive account explicitly connected by the user

Multi-device sharing occurs only through the Google Drive account explicitly connected by the user. Regular text, code and images are shared between devices using that same Drive workspace; Vault content remains local and is never synchronized.

10Google data

Google data: when Drive sync is enabled, the extension accesses the Google account email and only the files it creates or the user selects for Ultimate Clipboard Pro through the drive.file scope. The email identifies the connected workspace. Regular backup data is transferred directly between the extension and Google Drive for sync and restore; Vault content is excluded. Arcawand Soft and Dodo Payments do not receive Drive files or clipboard content.

11License data

License data: only when the user checks, activates, recovers, refreshes or removes a Pro license, the extension communicates with the dedicated Arcawand Soft license service. Activation or inspection may transmit the entered license key; routine authorization uses signed, renewable tokens. The service processes pseudonymous installation and license identifiers, a coarse device label, client version and technical security events, and verifies commercial authority with Dodo Payments. It never receives captures, searches, Vault data or Drive backups.

12Retention and deletion

Retention and deletion: local captures and preferences remain until the user deletes them, clears extension data or uninstalls the extension. Local ZIP backups remain wherever the user saves them; Drive backups remain in the user's Drive until deleted there. License records are retained while needed to operate, secure, revoke and document the license or to meet legal obligations; removing the license deactivates the device remotely before local authorization is removed when the service is available.

13Security

Security: license keys are not kept as ordinary long-term settings. Authorization tokens are cryptographically signed and device-bound; sensitive server-side license material is encrypted or hashed, and technical logs redact secrets. Google OAuth tokens are handled by Chrome identity APIs. No system can guarantee absolute security, so users should protect their Chrome profile, Drive account, exported backups and Vault password.

14Ultimate Clipboard Pro complies with the Chrome Web Store User Data Policy

Ultimate Clipboard Pro complies with the Chrome Web Store User Data Policy. Its use and transfer of information received from Google APIs also complies with the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the user-facing Drive connection, synchronization and restore features requested by the user; it is not used for advertising, credit decisions, profiling or unrelated purposes, and is not read by humans except where required for security, legal compliance or user-requested support with explicit consent.

15The public Arcawand Soft website is separate from the extension

The public Arcawand Soft website is separate from the extension. The extension contains no developer analytics. Website measurement, if accepted through the site's consent controls, concerns visits to the public website and does not receive extension captures, clipboard history, Vault content, Drive backups or extension searches.

16For privacy questions, contact the developer at contact@arcawand-soft

For privacy questions, contact the developer at contact@arcawand-soft.com. This policy may evolve as features evolve, while preserving local-first control, clear consent for Drive sync and strict separation between content and licensing.
