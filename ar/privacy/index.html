سياسة الخصوصية

نطاق هذه السياسة

تنطبق هذه السياسة على موقع ArcaWand Soft العام على arcawand-soft.com، بما في ذلك الصفحات العامة حول ArcaWand Soft وصفحات عرض المنتجات العامة وصفحات الاتصال وإعلانات الإطلاق والمحتوى المعلوماتي.

Proقد يكون للصفحات الخاصة بالقناة سياسة خصوصية خاصة بها. لا تصف سياسة الموقع العامة هذه مساحة التخزين الداخلية أو الأذونات أو سلوك الميزات لأي منتج أو امتداد للمتصفح.

من يقوم بتشغيل الموقع

يتم تشغيل موقع الويب بواسطة ArcaWand Soft. لطرح أسئلة الخصوصية أو طلبات البيانات أو أسئلة الدعم أو المخاوف الأمنية، اتصل بـ contact@arcawand-soft.com.

تتم معالجة البيانات عند زيارتك

الموقع هو في الأساس موقع معلوماتي ثابت ولا يتطلب حساب زائر. قد تقوم أنظمة الاستضافة والأمن والأداء تلقائيًا بمعالجة البيانات الفنية مثل عنوان IP أو الموقع التقريبي وتفاصيل المتصفح والجهاز وعنوان URL المطلوب والمحيل وتفضيلات اللغة وتاريخ ووقت الوصول ومعلومات الخطأ وإشارات التفاعل الأساسية.

يتم استخدام هذه المعلومات لتقديم الموقع وإبقائه متاحًا ومنع إساءة الاستخدام وتشخيص الأخطاء وقياس الأداء وفهم الصفحات المفيدة وتحسين جودة المحتوى.

رسائل الاتصال

عند الاتصال بـ ArcaWand Soft عبر البريد الإلكتروني أو من خلال رابط اتصال، نتلقى المعلومات التي تختار إرسالها: عنوان البريد الإلكتروني، والاسم إذا تم تقديمه، ومحتوى الرسالة، والموضوع، والمرفقات وأي سياق تقني طوعي.

نحن نستخدم هذه البيانات للرد وتقديم الدعم وإدارة الأعمال أو الاستفسارات الصحفية ومتابعة تعليقات المنتج والاحتفاظ بسجل معقول للتبادلات عند الحاجة.

إطلاق الإخطارات ونماذج البريد الإلكتروني

قد تدعو بعض الصفحات الزائرين إلى ترك عنوان بريد إلكتروني ليتم إعلامهم بشأن الإطلاق أو التحديث المهم. عندما يكون العنوان نشطًا، يتم استخدامه فقط للإشعارات المذكورة والاتصالات ذات الصلة المباشرة.

قد تعتمد النماذج على نقطة نهاية آمنة من جانب الخادم أو خدمة بريد إلكتروني. لا يتم أبدًا نشر مفاتيح واجهة برمجة التطبيقات الخاصة وأسرار الموفر عمدًا في كود موقع الويب العام. يمكنك إلغاء الاشتراك أو طلب الحذف في أي وقت.

التحليلات وملفات تعريف الارتباط والتخزين المحلي

قد يستخدم الموقع تحليلات تراعي الخصوصية أو نصوص أمنية أو أدوات أداء أو تشخيص الأخطاء. اعتمادًا على التكوين، قد تستخدم هذه الأدوات ملفات تعريف الارتباط أو التخزين المحلي أو بيانات التعريف المطلوبة أو تقنيات المتصفح المماثلة.

قد يتم تخزين تفضيلات اللغة أو اختيارات الواجهة أو حالات الرفض محليًا في متصفحك حتى يعمل الموقع بشكل متسق. يمكنك مسح ملفات تعريف الارتباط وبيانات الموقع من إعدادات المتصفح الخاص بك.

الاستضافة والخدمات الخارجية

تتم استضافة موقع الويب كموقع ثابت وقد يستخدم خدمات البنية التحتية للاستضافة وDNS وCDN والأمن والتحليلات وتسليم البريد الإلكتروني ومعالجة النماذج وروابط الدفع وصفحات التوزيع الخارجية.

يقوم هؤلاء المزودون بمعالجة البيانات المحدودة فقط حسب الحاجة لتقديم الخدمة أو تأمين الموقع أو توجيه الرسائل أو معالجة المدفوعات أو قياس الأداء أو الامتثال للالتزامات القانونية. تخضع صفحات الدفع الخارجية ومتاجر التطبيقات وChrome وصفحات المتجر الإلكتروني والمنصات الاجتماعية وروابط الجهات الخارجية لسياسات الخصوصية الخاصة بها.
