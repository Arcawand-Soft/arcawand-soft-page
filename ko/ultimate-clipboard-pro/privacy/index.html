개인 정보 보호 정책Ultimate Clipboard Pro

Ultimate Clipboard Pro는 로컬 우선 브라우저 확장으로 설계되었습니다. 이 페이지에서는 어떤 데이터가 처리되는지, 어디에 보관되는지, 어떤 선택적 서비스에 접속할 수 있는지, 사용자가 제어권을 유지하는 방법에 대해 설명합니다.

최종 업데이트 날짜: 2026년 8월 22일

개요

Ultimate Clipboard Pro는 사용자가 탐색하는 동안 텍스트, 코드 및 이미지를 캡처, 구성, 검색, 편집 및 재사용할 수 있도록 ArcaWand Soft에서 구축한 Chrome 확장입니다.

이 제품은 로컬 우선 철학으로 설계되었습니다. 즉, 일반적인 캡처 관리는 사용자 장치의 브라우저 확장 환경 내에서 이루어집니다.

개발자 및 연락처

Ultimate Clipboard Pro는 ArcaWand Soft에 의해 게시됩니다. 개인 정보 보호, 지원 또는 Chrome 웹 스토어 규정 준수 관련 질문이 있는 경우 contact@arcawand-soft.com으로 문의하세요.

Chrome 웹 스토어 사용자 데이터 약정

이 정책은 확장 프로그램의 동작과 Chrome 웹 스토어 개발자 대시보드에 제공된 개인정보 공개와 일치시키기 위한 것입니다. 공개, 허가 또는 기능이 변경되면 이에 따라 본 정책도 업데이트되어야 합니다.

확장 프로그램은 명확하게 설명된 제품 기능을 제공하거나 개선하기 위해서만 요청된 권한을 사용합니다. 관련 없는 검색 데이터를 수집하기 위해 권한을 사용하지 않습니다.

Google API 제한적 사용 선언문

사용자가 Google Drive 동기화를 활성화하면 확장 프로그램은 Google API로부터 정보를 수신하여 사용자의 Ultimate Clipboard Pro 백업 파일을 생성, 읽기, 업데이트 또는 복원할 수 있습니다.

Google API에서 받은 정보의 사용 및 전송은 제한된 사용 요구 사항을 포함하여 Chrome 웹 스토어 사용자 데이터 정책을 준수합니다. Google API 데이터는 사용자에게 제공되는 백업 및 동기화 기능을 제공하는 데에만 사용되며, 판매되거나 광고용으로 사용되지 않습니다.

세부 데이터 카테고리

사용자가 제공한 콘텐츠에는 캡처된 텍스트, 코드, 이미지, 스크린샷, 메모, 수동으로 작성한 제목, 카테고리 및 몽타주 콘텐츠가 포함될 수 있습니다.

소스 및 사용 메타데이터에는 페이지 제목, 소스 URL, 파비콘, 캡처 날짜, 버전 생성 날짜, 즐겨찾기, 고정 상태, 휴지통 상태, 저장소 상태, 표시 기본 설정, 언어, 테마, 강조 색상 및 사용자가 선택한 기타 설정이 포함될 수 있습니다.

라이선스 및 결제 상태에는 선택한 라이선스 또는 결제 제공업체를 통해 Pro 액세스를 확인하는 데 필요한 최소 정보가 포함될 수 있습니다. ArcaWand Soft는 내선 내부의 카드 번호를 처리하지 않습니다.

처리 목적

캡처를 저장하고, 확장 프로그램에 표시하고, 작업 공간 및 범주별로 구성하고, 검색하고, 버전을 생성하고, 삭제된 캡처를 복원하고, 캡처를 클립보드에 다시 복사하고, 백업을 내보내고, 선택적 드라이브 백업을 동기화하고 Pro 제한 또는 액세스를 적용하기 위해 데이터가 처리됩니다.

공유 및 제3자 서비스

캡처된 콘텐츠는 일반적인 로컬 사용을 위해 ArcaWand Soft와 공유되지 않습니다.

선택적인 제3자 서비스는 필요한 경우에만 연락할 수 있습니다. 사용자가 활성화할 수 있는 동기화를 위한 Google Drive, Pro 활성화를 위한 결제 또는 라이센스 제공업체, 공개 마케팅 사이트를 위한 기본 웹사이트 분석.

보안 및 전송

로컬 확장 데이터는 사용자가 내보내거나 복사하거나 드라이브 동기화를 활성화하거나 데이터를 이동하는 다른 명시적 기능을 사용하지 않는 한 브라우저 확장 환경에 유지됩니다.

선택적 서비스를 위해 네트워크 통신이 필요한 경우 HTTPS 또는 브라우저와 해당 공급자가 제공하는 보안 전송을 사용해야 합니다.

보유, 삭제 및 사용자 제어

사용자는 확장 프로그램 내의 캡처를 삭제하고, 가능한 경우 휴지통을 비우고, 로컬 백업을 내보내고, 백업을 복원하고, 드라이브 동기화 연결을 끊고, Chrome에서 확장 프로그램을 제거할 수 있습니다.

확장 프로그램을 제거하거나 Chrome 확장 저장소를 삭제하면 로컬 데이터가 삭제될 수 있습니다. Google Drive에 저장된 데이터는 사용자가 삭제할 때까지 사용자의 Google 계정에 남아 있습니다.

어린이 및 민감한 콘텐츠

Ultimate Clipboard Pro는 일반 사용자를 위한 생산성 도구이며 어린이를 대상으로 하지 않습니다. 사용자는 자신의 장치, 브라우저 및 백업 보안 모델을 이해하지 않는 한 매우 민감한 비밀을 저장하지 않아야 합니다.

국제적 사용

확장 프로그램과 웹사이트는 국제적으로 사용될 수 있습니다. 선택적 서비스 제공업체는 해당 서비스를 운영하는 국가에서 자체 약관 및 개인정보 보호정책에 따라 기술 데이터를 처리할 수 있습니다.

정책 업데이트

본 개인정보 보호정책은 제품, 법률, Chrome 웹 스토어 또는 공급자 변경 사항을 반영하기 위해 업데이트될 수 있습니다. 이 페이지에 표시된 날짜는 최신 게시된 업데이트를 나타냅니다.

확장 프로그램에서 처리하는 데이터

사용된 기능에 따라 확장 프로그램은 캡처된 텍스트, 코드, 이미지 데이터, 스크린샷, 페이지 메타데이터, 제목, 메모, 카테고리, 즐겨찾기, 고정 상태, 소스 URL, 파비콘, 버전 기록, 디스플레이 기본 설정 및 사용자 설정을 저장할 수 있습니다.

로컬 저장소

기본적으로 캡처된 콘텐츠와 설정은 브라우저 확장 저장소를 통해 로컬로 저장됩니다. 확장 프로그램을 제거하거나 브라우저 확장 프로그램 데이터를 지우면 사용자가 백업을 내보내거나 동기화하지 않은 경우 로컬 캡처가 제거될 수 있습니다.

선택적 Google Drive 동기화

사용자가 Google Drive를 연결하면 확장 프로그램은 사용자 드라이브 계정에 Ultimate Clipboard Pro 폴더를 생성하거나 업데이트하여 확장 프로그램 데이터를 백업하고 복원할 수 있습니다.

Google Drive 동기화는 선택 사항이며 사용자가 제어합니다.

결제 및 라이선스

Pro 라이선스 및 결제 흐름에서는 제3자 결제 및 라이선스 제공업체를 사용할 수 있습니다. 결제 세부정보는 공개 ArcaWand Soft 캡처 데이터베이스가 아닌 해당 제공업체에 의해 처리됩니다.

확장 프로그램은 Pro 기능을 잠금 해제하기 위해 라이선스 상태를 확인할 수 있습니다.

캡처한 콘텐츠를 판매하지 않습니다.

ArcaWand Soft는 캡처된 클립보드 콘텐츠를 판매하지 않습니다. 확장은 사용자의 개인 생산성, 구성 및 재사용을 위한 것입니다.

브라우저 권한

확장 프로그램은 캡처, 저장, 클립보드, 인터페이스 및 선택적 동기화 워크플로에 필요한 권한을 요청합니다. 사용자는 설치 또는 업데이트하기 전에 Chrome에서 확장 프로그램 권한을 검토할 수 있습니다.

백업 및 내보내기

로컬 JSON 또는 ZIP 내보내기는 사용자 요청에 따라 생성되므로 주의 깊게 저장해야 합니다. 내보낸 백업에 액세스할 수 있는 사람은 누구나 해당 내용을 읽을 수 있습니다.

보안 기대

사용자는 Chrome을 최신 상태로 유지하고 운영 체제 계정을 보호하며 신뢰할 수 없는 확장 프로그램을 피하고 백업을 신뢰할 수 있는 위치에 저장해야 합니다. Vault 액세스는 우연한 노출을 줄이지만 운영 체제 보안을 대체하지는 않습니다.

연락처

Windows PC와 Mac에서 같은 Drive 콘텐츠를 공유할 수 있나요?

기기 간 공유는 사용자가 명시적으로 연결한 Google Drive 계정을 통해서만 이루어집니다. 일반 텍스트, 코드 및 이미지는 공유되지만 Vault 콘텐츠는 로컬에 유지되며 동기화되지 않습니다.

동일한 라이선스로 Windows PC, Mac 및 기타 지원 컴퓨터를 같은 Google Drive 계정에 연결할 수 있습니다. 일반 텍스트, 코드 및 이미지를 하나의 동기화 공간에서 공유하며, 기기가 온라인이면 변경 사항이 보통 1분 이내에 반영됩니다.

라이선스를 몇 대의 기기에서 사용할 수 있나요?

하나의 라이선스는 최대 3대의 기기에서 활성화할 수 있습니다. 자리를 확보하려면 해당 기기의 설정에서 라이선스를 삭제하세요. 확장 프로그램은 원격 비활성화를 확인한 후 로컬에서 삭제합니다. ⚠ 확장 프로그램을 제거하기 전에 반드시 라이선스를 먼저 삭제한 뒤 제거하세요. 먼저 제거하면 활성화 자리가 확보되지 않습니다.
