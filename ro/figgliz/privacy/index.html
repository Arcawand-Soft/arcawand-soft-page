Politica de confidențialitateFiggliz

Figgliz limitează colectarea datelor și explică ce rămâne local, ce trece prin VPS și ce este folosit pentru siguranță.

Date locale

Extensia poate stoca local limba, tema, starea lansatorului, preferințele, ID-ul anonim, blocurile, contoarele de utilizare și starea licenței.

Datele serverului VPS

VPS procesează prezența, coada de așteptare, potrivirea, stările, semnalizarea WebRTC, cotele, indicativele de acțiune, verificarea licenței, rapoartele și protecțiile anti-abuz.

Conversații

Mesajele și notele vocale folosesc WebRTC DataChannel atunci când este posibil. Serverul de aplicații nu este conceput ca o bază de date cu istoricul conversațiilor.

Cameră și microfon

Chrome solicită permisiunea înainte de orice acces la cameră sau microfon. Puteți opri videoclipul, dezactiva sunetul, întrerupeți camera sau revocați permisiunea.

Fundaluri video și segmentare

Neclaritatea și fundalurile webcam sunt aplicate local cu resurse incluse. Ei compun fluxul dvs. video; nu sunt folosite pentru a vă identifica camera.

Jocuri

Jocurile fac schimb de acțiuni tehnice și stări între cei doi utilizatori. Gazduirea jocului VPS este momentan dezactivată pentru a păstra stabilitatea serverului.

Licențe și plăți

Dodo Payments gestionează plata. Extensia și serverul verifică exact produsul, starea, perioada și drepturile necesare, fără a stoca detaliile complete ale cardului.

Rapoarte și moderare

Un raport poate include motiv, comentariu, ID-uri anonime, hash-uri IP, metadate și elemente strict utile pentru moderare.

Fără vânzare

Figgliz nu vinde date personale, mesaje, note vocale sau videoclipuri și nu le folosește pentru publicitate direcționată.

Controalele tale

Puteți deveni indisponibil, edita setările, ascunde lansatorul, bloca, raporta, elimina licența locală, gestiona planul și revoca camera/microfonul.

Contact

Asistență, confidențialitate, siguranță sau facturare: contact@arcawand-soft.com.

Istoricul local și controlul utilizatorului

Când istoricul este activat, elementele de conversație eligibile sunt păstrate local de extensia de pe dispozitivul Utilizatorului. Utilizatorul rămâne în control: o singură conversație sau întregul istoric poate fi ștearsă din interfața dedicată.

Parolă și fără acces la server

Istoricul este protejat de o parolă locală și de o întrebare secretă. Parola nu este destinată să fie trimisă la server pentru citire de la distanță. Dacă este uitat sau resetat, este necesară ștergerea completă a istoricului local pentru a preveni accesul neautorizat.

Verificarea cotelor și a creditului

Pentru a aplica limitele Free, creditele cadou și drepturile Plus/Pro, Figgliz poate verifica pe server starea licenței, ID-ul local de instalare, adresa IP sau hash, fusul orar necesar pentru contoarele zilnice, jetoanele de eveniment de acceptare și jetoanele de acțiune. Aceste verificări previn înșelăciunea și nu înseamnă stocarea pe server a conținutului conversației.
