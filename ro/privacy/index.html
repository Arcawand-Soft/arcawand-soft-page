Politica de confidențialitate

Cum gestionează site-ul web ArcaWand Soft datele tehnice, mesajele de contact, notificările de lansare, analizele, serviciile externe și drepturile utilizatorului.

Domeniul de aplicare al acestei politici

Această politică se aplică site-ului web public ArcaWand Soft la arcawand-soft.com, inclusiv pagini generale despre ArcaWand Soft, pagini publice de prezentare a produselor, pagini de contact, anunțuri de lansare și conținut informațional.

Paginile specifice Product pot avea propria lor politică de confidențialitate. Această politică generală a site-ului web nu descrie stocarea internă, permisiunile sau comportamentul caracteristicilor niciunui produs sau extensie de browser.

Cine operează site-ul

Site-ul web este operat de ArcaWand Soft. Pentru întrebări privind confidențialitatea, solicitări de date, întrebări de asistență sau probleme de securitate, contactați contact@arcawand-soft.com.

Datele prelucrate atunci când vizitați

Site-ul web este în principal un site informațional static și nu necesită un cont de vizitator. Sistemele de găzduire, securitate și performanță pot procesa automat date tehnice, cum ar fi adresa IP sau locația aproximativă, detaliile browserului și dispozitivului, adresa URL solicitată, referința, preferința de limbă, data și ora de acces, informații de eroare și semnale de interacțiune de bază.

Aceste informații sunt folosite pentru a livra site-ul, a-l păstra disponibil, a preveni abuzurile, a diagnostica erorile, a măsura performanța, a înțelege ce pagini sunt utile și a îmbunătăți calitatea conținutului.

Mesaje de contact

Când contactați ArcaWand Soft prin e-mail sau printr-un link de contact, primim informațiile pe care alegeți să le trimiteți: adresa de e-mail, numele dacă este furnizat, conținutul mesajului, subiectul, atașamentele și orice context tehnic voluntar.

Folosim aceste date pentru a răspunde, pentru a oferi asistență, pentru a gestiona întrebări de afaceri sau de presă, pentru a urmări feedback-ul despre produse și pentru a păstra o evidență rezonabilă a schimburilor atunci când este necesar.

Lansați notificări și formulare de e-mail

Unele pagini pot invita vizitatorii să lase o adresă de e-mail pentru a fi notificați despre o lansare sau o actualizare importantă. Când este activă, adresa este utilizată numai pentru notificarea declarată și comunicarea direct legată.

Formularele se pot baza pe un punct final securizat pe partea de server sau pe un serviciu de e-mail. Cheile API private și secretele furnizorului nu sunt niciodată publicate intenționat în codul site-ului public. Vă puteți dezabona sau solicita ștergerea oricând.

Analytics, cookie-uri și stocare locală

Site-ul poate utiliza analize care țin cont de confidențialitate, scripturi de securitate, instrumente de performanță sau diagnosticare a erorilor. În funcție de configurație, aceste instrumente pot utiliza cookie-uri, stocare locală, solicitarea de metadate sau tehnologii similare de browser.

Preferințele de limbă, opțiunile de interfață sau stările de respingere pot fi stocate local în browserul dvs., astfel încât site-ul să se comporte constant. Puteți șterge cookie-urile și datele site-ului din setările browserului dvs.

Gazduire si servicii externe

Site-ul web este găzduit ca site static și poate utiliza servicii de infrastructură pentru găzduire, DNS, CDN, securitate, analiză, livrare prin e-mail, procesare formulare, link-uri de plată și pagini de distribuție externe.

Acești furnizori prelucrează date limitate numai în măsura în care este necesar pentru a-și furniza serviciul, a securiza site-ul, a direcționa mesaje, a procesa plăți, a măsura performanța sau a respecta obligațiile legale. Paginile externe de plată, magazinele de aplicații, paginile magazinului web Chrome, platformele sociale și linkurile de la terți sunt guvernate de propriile politici de confidențialitate.

Scopuri și temeiuri juridice

În funcție de locația dvs., prelucrarea se poate baza pe interesul legitim în operarea, securizarea și îmbunătățirea site-ului web, consimțământul acolo unde este necesar pentru analize opționale sau comunicări de marketing, necesitatea contractuală atunci când se răspunde la o solicitare directă și obligațiile legale în care trebuie păstrate înregistrările.

Partajarea datelor

ArcaWand Soft nu vinde datele personale colectate prin intermediul site-ului web. Datele limitate pot fi partajate cu furnizorii de servicii care ajută la găzduirea, securizarea, analizarea, operarea sau comunicarea prin intermediul site-ului sau atunci când este necesar pentru conformitatea legală, securitate, prevenirea fraudei sau solicitări legale legitime.

Retentie

Jurnalele tehnice sunt păstrate doar pentru o perioadă rezonabilă necesară pentru securitate, depanare, analiză și fiabilitate operațională. E-mailurile de contact sunt păstrate atâta timp cât este necesar pentru a răspunde cererii, pentru a menține înregistrările comerciale și pentru a proteja interesele legitime. Datele de înregistrare la notificări sunt păstrate până la dezabonare, cerere de ștergere sau curățare a serviciului.

Securitate

Site-ul folosește HTTPS și furnizori de infrastructură de renume. Niciun site web public nu poate garanta securitatea absolută, dar site-ul este menținut cât mai simplu și static posibil, evită colectarea inutilă de date și evită expunerea acreditărilor private în codul front-end.

Drepturile tale

În funcție de țara sau regiunea dvs., este posibil să aveți drepturi de a accesa, corecta, șterge, restricționa sau opune prelucrării, retrage consimțământul, solicita portabilitatea sau depune o plângere la o autoritate de protecție a datelor.

Pentru exercitarea acestor drepturi, contactați contact@arcawand-soft.com. Este posibil să avem nevoie de suficiente informații pentru a verifica și a procesa cererea.

Copii

Site-ul nu este direcționat către copii și nu solicită cu bună știință date personale de la copii. Dacă credeți că un copil a furnizat date personale prin intermediul site-ului, contactați-ne pentru a le putea revizui și șterge acolo unde este cazul.

Modificări ale acestei politici

Această politică poate fi actualizată atunci când site-ul web, cerințele legale, furnizorii de servicii sau practicile de confidențialitate se modifică. Cea mai recentă versiune publicată pe această pagină se aplică de la data la care este disponibilă.
