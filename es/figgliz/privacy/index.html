Política de privacidad

Politica de privacidadFiggliz

Figgliz limita los datos recogidos y explica que queda local, que pasa por el VPS y que se usa para seguridad.

Datos locales

Se pueden guardar idioma, tema, launcher, preferencias, ID anonimo, bloqueos, contadores y licencia.

Datos VPS

El VPS trata presencia, cola, matching, signaling, cuotas, tokens, licencias, reportes y anti-abuso.

Conversaciones

Mensajes y voz usan WebRTC DataChannel si es posible; el servidor no es un historial de chats.

Camara y microfono

Chrome pide permiso. Puedes detener video, silenciar, pausar o revocar permisos.

Fondos de video

El desenfoque y fondos se aplican localmente y componen el flujo de video.

Juegos

Los juegos intercambian acciones y estados; en modo VPS el servidor puede sincronizar y limitar trampas.

Licencias y pagos

Dodo Payments procesa pagos; se verifica producto, estado, periodo y derechos sin guardar tarjeta completa.

Reportes

Un reporte puede incluir razon, comentario, IDs anonimos, hashes IP y metadatos utiles.

No venta

No vendemos datos, mensajes, voz ni video.

Controles

Puedes cambiar ajustes, ocultar launcher, bloquear, reportar, gestionar licencia y revocar permisos.

Contact

Soporte, privacidad, seguridad o facturacion: contact@arcawand-soft.com.

Historial local y control del usuario

Cuando el historial está activado, los elementos admisibles de conversación se conservan localmente por la extensión en el dispositivo del Usuario. El Usuario conserva el control: puede borrar una conversación concreta o todo el historial desde la interfaz dedicada.

Contraseña y ausencia de acceso servidor

El historial se protege con una contraseña local y una pregunta secreta. La contraseña no está destinada a enviarse al servidor para una lectura remota. En caso de olvido o restablecimiento, se exige la eliminación completa del historial local para evitar accesos no autorizados.

Verificacion de cupos y creditos

Para aplicar limites Free, cr?ditos para regalar y derechos Plus/Pro, Figgliz puede verificar en el servidor licencia, identificador local de instalacion, IP o hash, huso horario, tokens de accion y aceptaciones. Esto evita trampas sin almacenar el contenido de las conversaciones en el servidor.
