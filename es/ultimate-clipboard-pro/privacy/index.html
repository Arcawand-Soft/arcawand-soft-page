Política de privacidad

Ultimate Clipboard Pro está diseñado para trabajo privado y controlado por el usuario. Procesa contenido del portapapeles solo para funciones solicitadas: captura, organización, búsqueda local, copia, edición, backup, restauración y Drive opcional.

22 de agosto de 2026

01Ultimate Clipboard Pro está diseñado para trabajo privado y controlado por el usuario

Ultimate Clipboard Pro está diseñado para trabajo privado y controlado por el usuario. Procesa contenido del portapapeles solo para funciones solicitadas: captura, organización, búsqueda local, copia, edición, backup, restauración y Drive opcional.

02Los datos normales quedan en chrome

Los datos normales quedan en chrome.storage.local en el perfil Chrome. La extensión no opera un servidor de contenido de Arcawand Soft ni envía contenidos, imágenes, notas, categorías, búsquedas, Caja fuerte o ajustes al desarrollador.

03Los datos locales pueden incluir textos, códigos, imágenes, capturas Markdown, pantallas, vistas previas, títulos, notas, etiquetas, categorías, favoritos, fijados, fechas, dominios, URLs, favicons y ajustes

Los datos locales pueden incluir textos, códigos, imágenes, capturas Markdown, pantallas, vistas previas, títulos, notas, etiquetas, categorías, favoritos, fijados, fechas, dominios, URLs, favicons y ajustes.

04La extensión no vende, alquila, intercambia ni explota comercialmente contenido del usuario

La extensión no vende, alquila, intercambia ni explota comercialmente contenido del usuario. No requiere cuenta, contraseña, nombre, teléfono ni perfil de identidad para uso normal.

05No contiene publicidad, targeting, perfilado ni analíticas del desarrollador

No contiene publicidad, targeting, perfilado ni analíticas del desarrollador. No envía analíticas de navegación, búsqueda, timeline, logs de backup ni telemetría a Arcawand Soft.

06Los permisos de Chrome se utilizan solo para funciones visibles del producto

Los permisos de Chrome se utilizan solo para funciones visibles del producto: captura en páginas compatibles, lectura y escritura en el portapapeles activada por el usuario, almacenamiento local, menús contextuales, vistas de extensión, acciones de pestaña activa, capturas de pantalla, OCR local, ubicación con reconocimiento de monitor, importación/exportación de ZIP local y sincronización de archivos de identidad y Drive de Google solo cuando el usuario lo habilita.

07El usuario controla sus datos

El usuario controla sus datos: editar, eliminar, clasificar, mover, proteger en Caja fuerte, exportar ZIP, restaurar localmente, sincronizar a Drive en Pro o borrar el almacenamiento.

08Dodo Payments actúa como comerciante registrado para el pago Pro y procesa el pago, los impuestos de transacción aplicables y la documentación de pago bajo sus propios términos

Dodo Payments actúa como comerciante registrado para el pago Pro y procesa el pago, los impuestos de transacción aplicables y la documentación de pago bajo sus propios términos. La extensión se comunica con el servicio de licencia dedicado Arcawand Soft para operaciones de licencia; ese servicio verifica el derecho comercial con Dodo. Ninguno de los flujos recibe contenido capturado ni copias de seguridad de Drive.

09El uso compartido entre dispositivos solo pasa por la cuenta de Google Drive conectada expresamente por el usuario

El uso compartido entre dispositivos solo pasa por la cuenta de Google Drive conectada expresamente por el usuario. Los textos, códigos e imágenes normales se comparten en ese espacio; la Caja fuerte permanece local y nunca se sincroniza.

10alcance del archivo

alcance del archivo. El correo electrónico identifica el espacio de trabajo conectado. Los datos de respaldo regulares se transfieren directamente entre la extensión y Google Drive para sincronizarlos y restaurarlos; El contenido de la bóveda está excluido. Arcawand Soft y Dodo Payments no reciben archivos de Drive ni contenido del portapapeles.

11Datos de licencia

Datos de licencia: solo cuando el usuario verifica, activa, recupera, actualiza o elimina una licencia Pro, la extensión se comunica con el servicio de licencia dedicado Arcawand Soft. La activación o inspección puede transmitir la clave de licencia ingresada; La autorización de rutina utiliza tokens firmados y renovables. El servicio procesa identificadores de licencia y de instalación seudónimos, una etiqueta aproximada del dispositivo, la versión del cliente y eventos técnicos de seguridad, y verifica la autoridad comercial con Dodo Payments. Nunca recibe capturas, búsquedas, datos de Vault ni copias de seguridad de Drive.

12Retención y eliminación

Retención y eliminación: las capturas y preferencias locales permanecen hasta que el usuario las elimina, borra los datos de la extensión o desinstala la extensión. Las copias de seguridad ZIP locales permanecen dondequiera que el usuario las guarde; Las copias de seguridad de Drive permanecen en el Drive del usuario hasta que se eliminan allí. Los registros de licencia se conservan mientras sean necesarios para operar, asegurar, revocar y documentar la licencia o para cumplir obligaciones legales; Al quitar la licencia, se desactiva el dispositivo de forma remota antes de que se elimine la autorización local cuando el servicio está disponible.

13Seguridad

Seguridad: las claves de licencia no se guardan como configuraciones habituales a largo plazo. Los tokens de autorización están firmados criptográficamente y vinculados al dispositivo; El material confidencial de licencia del lado del servidor está cifrado o codificado, y los registros técnicos redactan secretos. Los tokens de Google OAuth son manejados por las API de identidad de Chrome. Ningún sistema puede garantizar una seguridad absoluta, por lo que los usuarios deben proteger su perfil de Chrome, su cuenta de Drive, sus copias de seguridad exportadas y su contraseña de Vault.

14Ultimate Clipboard Pro cumple con la Política de datos de usuario de Chrome Web Store

Ultimate Clipboard Pro cumple con la Política de datos de usuario de Chrome Web Store. Su uso y transferencia de información recibida de las API de Google también cumple con la Política de datos de usuario de los servicios API de Google, incluidos los requisitos de uso limitado. Los datos de usuario de Google se utilizan únicamente para proporcionar las funciones de conexión, sincronización y restauración de Drive orientadas al usuario solicitadas por el usuario; no se utiliza para publicidad, decisiones crediticias, elaboración de perfiles o fines no relacionados, y no es leído por humanos excepto cuando sea necesario por motivos de seguridad, cumplimiento legal o soporte solicitado por el usuario con consentimiento explícito.

15El sitio web público de Arcawand Soft está separado de la extensión

El sitio web público de Arcawand Soft está separado de la extensión. La extensión no contiene análisis de desarrolladores. La medición del sitio web, si se acepta a través de los controles de consentimiento del sitio, se refiere a las visitas al sitio web público y no recibe capturas de extensiones, historial del portapapeles, contenido de Vault, copias de seguridad de Drive ni búsquedas de extensiones.

16Para privacidad, contacta a contact@arcawand-soft

Para privacidad, contacta a contact@arcawand-soft.com. Esta política puede evolucionar con las funciones manteniendo control local-first, consentimiento claro para Drive y separación entre contenido y licencia.
