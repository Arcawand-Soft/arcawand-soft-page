よくある質問

この拡張機能は、ローカルファーストの哲学に基づいて設計されています。通常のキャプチャ管理は、デバイスのブラウザ拡張機能環境で行われます。 Google Drive 同期、支払い、ライセンスなどのオプション サービスは分離され、特定の目的にのみ使用されます。

もう毎日コピペしてます。 Ultimate Clipboard Pro が必要なのはなぜですか?

通常のクリップボードは一時的なものであるためです。 Ultimate Clipboard Pro は、コピーしたものを構造化されたワークスペースに変換します。テキスト、コード、画像は引き続き利用可能で、検索可能であり、次のコピー後に消えるのではなく、再利用する準備ができています。

この拡張機能は本当に誰のためのものなのでしょうか?

これは、プロンプトと回答を保存する AI ユーザー、スニペットを保持する開発者、ソースを収集する研究者、コンテンツを準備するクリエイター、コピーを再利用するマーケティング担当者、および貴重なコピーされた素材を失うことを嫌うすべての人など、ブラウジング中に有用な情報を収集する要求の厳しいユーザーを対象としています。

基本的なクリップボード履歴との違いは何ですか?

基本的な歴史は通常、長い年表になります。 Ultimate Clipboard Pro は、テキスト、コード、画像用の専用ワークスペースに加え、タイトル、カテゴリ、ソース URL、メモ、お気に入り、ピン、ビジュアル ソース履歴、高度な検索、およびバージョニングやモンタージュなどの Pro ワークフローを提供します。

それを使って何をキャプチャできますか?

Markdown では、テキスト、コード、画像、スクリーンショット、および利用可能な場合は Web ページをキャプチャできます。この拡張機能は、プレーン テキストだけでなく、ユーザーが毎日コピーする実際の資料をカバーするように設計されています。

コードをインテリジェントにキャプチャしますか?

はい。コード キャプチャは通常のテキストとは別に扱われ、言語、ソース、分類などの有用なコンテキストを保持できます。開発者や技術ユーザーにとって、これにより、後でスニペットを見つけて再利用することがはるかに簡単になります。

役に立つものをコピーした後はどうなりますか?

キャプチャは、フローティング ランチャー、サイド パネル、およびフル マネージャーに表示できます。そこから、ブラウジング フローを中断することなく、再度使用したり、分類したり、お気に入りにしたり、ピン留めしたり、検索したり、作業を続行したりできます。

膨大なリストをスクロールする代わりにキャプチャを整理できますか?

はい。カテゴリとサブカテゴリ、個別のテキスト/コード/画像スペース、お気に入り、固定アイテム、ゴミ箱、保管庫ワークフローを使用できます。目標は、コピーした素材が埋もれず、整理されていると感じられるようにすることです。

後で何かをどれくらい早く見つけることができますか?

検索は実際の検索を目的として構築されています。キャプチャ コンテンツに加えて、タイトル、メモ、ソース ドメイン、URL などの有用なメタデータを使用できます。つまり、何をコピーしたか、どこから来たのか、どのように説明したかによって検索できるということです。

キャプチャがどこから来たのかを思い出すのに役立ちますか?

はい。ソース コンテキストは、この製品の最も強力な利点の 1 つです。キャプチャではページ情報とソース URL を保持でき、視覚的なソース履歴により、保存した内容の元に戻ることができます。

タイトルとメモが役立つのはなぜですか?

タイトルとメモを使用すると、生のキャプチャを意味のあるものに変えることができます。断片を偶然認識するのではなく、名前を付けて説明すると、数週間後に再度見つけやすくなります。

バージョン管理は何に使用されますか?

バージョン管理により、Pro ユーザーは同じテキストまたはコード キャプチャの複数のバージョンを 1 つのアイテム内に保持できます。これは、プロンプト、返信、スニペット、下書き、重複を排除して進化させたい改善に最適です。

キャプチャモンタージュとは何ですか?

モンタージュを使用すると、複数のテキスト キャプチャを 1 つのきれいに結合されたテキストにまとめることができます。これは、プロンプト、レポート、概要、概要、研究ノート、または再利用可能なコンテンツ ブロックを準備するのに役立ちます。

画像のキャプチャやスクリーンショットについてはどうですか?

Ultimate Clipboard Pro はテキストに限定されません。画像のキャプチャとスクリーンショットは、独自のワークスペースとコントロールを使用して、同じ生産性ロジック内で保存、整理、再利用できます。

私のコンテンツは非公開ですか?

この拡張機能は、ローカルファーストの哲学に基づいて設計されています。通常のキャプチャ管理は、デバイスのブラウザ拡張機能環境で行われます。 Google Drive 同期、支払い、ライセンスなどのオプション サービスは分離され、特定の目的にのみ使用されます。

Google Drive を使用する必要がありますか?

いいえ。Google Drive 同期はオプションです。ローカルで作業し、ローカルのエクスポート/復元を使用できます。ドライブ同期は、自分の Google アカウント全体のクラウド バックアップと復元パスを必要とするユーザー向けです。

無料版では何ができますか?

無料版では、限られたキャプチャと小規模なツール セットでワークフローを理解できます。これは、製品を試して、構造化されたクリップボード ワークスペースが日常にどれだけの価値をもたらすかを確認するのに役立ちます。

Pro にアップグレードする理由は何ですか?

Proは日常使用に適しています。無制限のキャプチャ、ボールト アクセス、ゴミ箱の回復、バージョン管理、モンタージュ、その他のツール、高度なワークフロー、およびオプションの Google Drive 同期のロックが解除されます。延長が勤務時間の一部になった場合、Pro はその煩わしさを取り除きます。

インストール後、最初に何を試すべきですか?

有用なテキスト、コード スニペット、画像をキャプチャします。次に、マネージャーを開き、タイトルを追加し、1 つのアイテムを分類し、ソースで検索して、キャプチャの再利用を試みます。最初のループは、拡張機能がクリップボードの履歴以上のものである理由を示しています。

ブラウジングが遅くなりますか?

この拡張機能は、ページを占有することなくワークフローの近くに留まるように構築されています。フローティング ランチャーを使用すると素早いアクセスが可能になり、より詳細な構成が必要な場合は完全なマネージャーが開きます。

開発者に連絡するにはどうすればよいですか?

サポート、プライバシーに関する質問、製品のフィードバック、ビジネス上のリクエストについては、ArcaWand Soft (contact@arcawand-soft.com) にお問い合わせください。

ライセンスは何台の端末で使えますか？

1つのライセンスは最大3台の端末で有効化できます。枠を解放するには、その端末の設定でライセンスを削除してください。拡張機能はリモート無効化を確認してからローカル削除を行います。⚠ アンインストール前に必ずライセンスを削除し、その後で拡張機能を削除してください。先にアンインストールしても枠は解放されません。

Windows PC と Mac で同じ Drive コンテンツを共有できますか？

はい。同じライセンスを最大3台のコンピューターで有効化し、すべてを同じ Google Drive アカウントに接続します。通常のテキスト、コード、画像が共有されます。端末がオンラインで Drive が利用可能なら、追加や削除は通常1分以内に反映されます。Vault は同期されません。

拡張機能がローカルにある場合でも、拡張機能はどのようなデータを処理しますか?

その機能を提供するために、拡張機能はユーザーが意図的に作成したキャプチャとメタデータ (テキスト、コード、画像、スクリーンショット、タイトル、メモ、カテゴリ、タイムスタンプ、ソース URL、ファビコン、検索、設定など) を処理します。これらはデフォルトで Chrome プロファイルに残り、Arcawand Soft には送信されません。

Google ドライブには具体的に何が送信されるのでしょうか?

ユーザーがドライブに接続して同期を有効にした場合にのみ、定期的なキャプチャ、メタデータ、同期された設定がそのユーザーのドライブ内の Ultimate Clipboard Pro バックアップ ワークスペースに書き込まれます。 Vault のコンテンツは決して含まれません。この拡張機能は、ドライブ内のすべてのファイルへの無制限のアクセスではなく、drive.file アクセスを使用します。

Arcawand Soft または Dodo Payments には何が送信されますか?

専用の Arcawand ライセンス サービスは、確認、アクティベーション、更新、回復、失効、および非アクティベーションに必要なライセンスと技術的なデバイス データのみを受け取ります。 Dodo Payments の商業的権利を確認します。キャプチャ、スクリーンショット、メモ、検索、Vault コンテンツ、ドライブのバックアップがそのフローに含まれることはありません。

Arcawand Soft、Dodo Payments、または Google は私のクリップボード履歴を読み取ることができますか?

Arcawand Soft および Dodo Payments はクリップボード履歴を受け取りません。 Google ドライブは、ユーザーが自分のアカウントで同期を有効にした場合にのみ、定期的なバックアップ データを保存します。開発者はそのデータを広告やプロファイリングに使用したり、ライセンスやサポートの一環としてデータにアクセスしたりすることはありません。

データとバックアップを削除するにはどうすればよいですか?

拡張機能から個々のアイテムまたはローカル データを削除し、選択したフォルダーから保存された ZIP バックアップを削除し、ドライブが使用されていた場合は Google ドライブから Ultimate Clipboard Pro バックアップ ワークスペースを削除します。アンインストールする前にアクティブなライセンスを削除して、リモート デバイス スロットを解放します。

拡張機能が広範な Chrome 権限を要求するのはなぜですか?

各権限は、サポートされているページでのキャプチャ、ユーザーによるクリップボード アクセス、ローカル ストレージ、コンテキスト メニュー、スクリーンショット、拡張機能サーフェス、モニター対応の配置、ローカル バックアップ ファイル、およびオプションの Google ID/ドライブ同期などの目に見える機能をサポートしています。許可は、広告、データの販売、または無関係な閲覧監視には使用されません。

拡張機能には分析または追跡が含まれていますか?

この拡張機能には、開発者分析、広告トラッカー、または行動プロファイリングは含まれていません。別の公開 Arcawand Soft Web サイトは、同意コントロールで許可された場合にのみ Web サイトへのアクセスを測定できます。これらの測定値は、拡張コンテンツやクリップボード アクティビティを受け取りません。

使用および購入に関する法的条件はどこで確認できますか?

利用規約はソフトウェアの使用を規定します。販売条件では、Dodo Payments の登録販売者としての役割を含む、1 回限りの Pro の購入、配送、アクティベーション、引き出し、返金のフレームワークについて説明しています。どちらも、すべての拡張機能メニューおよび公式製品 Web サイトから入手できます。
