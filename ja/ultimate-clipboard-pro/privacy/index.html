プライバシーポリシーUltimate Clipboard Pro

Ultimate Clipboard Pro は、ローカルファーストのブラウザー拡張機能として設計されています。このページでは、どのようなデータが処理されるか、どこに保管されるか、どのオプション サービスにアクセスできるか、およびユーザーがどのように制御し続けるかについて説明します。

最終更新日: 2026 年 5 月 13 日

概要

Ultimate Clipboard Pro は、ArcaWand Soft によって構築された Chrome 拡張機能で、ユーザーがブラウジング中にテキスト、コード、画像をキャプチャ、整理、検索、編集、再利用できるようにします。

この製品はローカルファーストの理念に基づいて設計されており、通常のキャプチャ管理はユーザーデバイスのブラウザ拡張機能環境内で行われます。

開発者と連絡先

Ultimate Clipboard Pro は ArcaWand Soft によって公開されています。プライバシー、サポート、Chrome Web ストアのコンプライアンスに関する質問については、contact@arcawand-soft.com までお問い合わせください。

Chrome Web ストアのユーザー データのコミットメント

このポリシーは、拡張機能の動作と、Chrome Web ストア開発者ダッシュボードで提供されるプライバシーの開示に一致することを目的としています。開示、許可、機能が変更された場合は、それに応じてこのポリシーを更新する必要があります。

拡張機能は、明確に説明された製品機能を提供または改善するためにのみ、要求された権限を使用します。無関係な閲覧データを収集するためにアクセス許可を使用しません。

Google APIの限定使用に関する声明

ユーザーが Google Drive 同期を有効にすると、拡張機能は Google API から情報を受け取り、ユーザーの Ultimate Clipboard Pro バックアップ ファイルを作成、読み取り、更新、または復元することがあります。

Google API から受け取った情報の使用と転送は、限定使用要件を含む Chrome ウェブストア ユーザー データ ポリシーに準拠します。 Google API データは、ユーザー向けのバックアップおよび同期機能を提供するためにのみ使用され、販売されたり、広告に使用されたりすることはありません。

詳細データカテゴリ

ユーザー提供のコンテンツには、キャプチャされたテキスト、コード、画像、スクリーンショット、メモ、手書きのタイトル、カテゴリ、モンタージュ コンテンツが含まれる場合があります。

ソースおよび使用状況のメタデータには、ページ タイトル、ソース URL、ファビコン、キャプチャ日、バージョン作成日、お気に入り、固定状態、ゴミ箱状態、ボールト状態、表示設定、言語、テーマ、アクセント カラー、およびユーザーが選択したその他の設定が含まれる場合があります。

ライセンスと支払いステータスには、選択したライセンスまたは支払いプロバイダーを介した Pro アクセスを確認するために必要な最小限の情報が含まれる場合があります。 ArcaWand Soft は、拡張機能内のカード番号を処理しません。

処理の目的

データは、キャプチャの保存、拡張機能での表示、ワークスペースおよびカテゴリ別の整理、検索、バージョンの作成、削除されたキャプチャの復元、クリップボードへのキャプチャのコピー、バックアップのエクスポート、オプションのドライブ バックアップの同期、および Pro の制限またはアクセスの適用のために処理されます。

共有サービスとサードパーティサービス

キャプチャされたコンテンツは、通常のローカル使用のために ArcaWand Soft と共有されません。

オプションのサードパーティ サービスは、必要な場合にのみ連絡できます。たとえば、ユーザーが有効にした同期のための Google Drive、Pro アクティベーションのための支払いプロバイダーまたはライセンス プロバイダー、および公開マーケティング サイトのための基本的な Web サイト分析です。

セキュリティと送信

ローカル拡張機能データは、ユーザーがエクスポート、コピー、ドライブ同期を有効にするか、データを移動する別の明示的な機能を使用しない限り、ブラウザ拡張機能環境に残ります。

オプション サービスでネットワーク通信が必要な場合は、HTTPS またはブラウザと関連プロバイダーが提供する安全なトランスポートを使用する必要があります。

保存、削除、ユーザー制御

ユーザーは、拡張機能内のキャプチャを削除し、利用可能な場合はゴミ箱を空にし、ローカル バックアップをエクスポートし、バックアップを復元し、ドライブの同期を切断し、Chrome から拡張機能を削除できます。

拡張機能をアンインストールするか、Chrome 拡張機能ストレージをクリアすると、ローカル データが削除される可能性があります。 Google Drive に保存されたデータは、ユーザーが削除するまでユーザーの Google アカウントに残ります。

子供と機密性の高いコンテンツ

Ultimate Clipboard Pro は一般ユーザー向けの生産性向上ツールであり、子供向けではありません。ユーザーは、自分のデバイス、ブラウザ、バックアップのセキュリティ モデルを理解していない限り、機密性の高い機密情報を保存しないようにする必要があります。

国際利用

拡張機能と Web サイトは国際的に使用できます。オプションのサービスプロバイダーは、独自の規約およびプライバシーポリシーに従って、事業を展開する国で技術データを処理する場合があります。

ポリシーの更新

このプライバシー ポリシーは、製品、法律、Chrome Web ストアまたはプロバイダーの変更を反映するために更新される場合があります。このページに表示される日付は、最新の公開された更新を示します。

拡張機能で扱うデータ

使用される機能に応じて、拡張機能はキャプチャされたテキスト、コード、画像データ、スクリーンショット、ページのメタデータ、タイトル、メモ、カテゴリ、お気に入り、固定状態、ソース URL、ファビコン、バージョン履歴、表示設定、およびユーザー設定を保存する場合があります。

ローカルストレージ

デフォルトでは、キャプチャされたコンテンツと設定はブラウザ拡張ストレージを介してローカルに保存されます。拡張機能を削除するか、ブラウザ拡張機能のデータをクリアすると、ユーザーがバックアップをエクスポートまたは同期していない限り、ローカル キャプチャが削除される可能性があります。

オプションの Google Drive 同期

ユーザーが Google Drive に接続すると、拡張機能はユーザーのドライブ アカウントに Ultimate Clipboard Pro フォルダーを作成または更新して、拡張機能のデータをバックアップおよび復元することがあります。

Google Drive 同期はオプションであり、ユーザーによって制御されます。

支払いとライセンス

Pro ライセンスおよび支払いフローでは、サードパーティの支払いおよびライセンス プロバイダーを使用する場合があります。支払いの詳細は、パブリック ArcaWand Soft キャプチャ データベースではなく、これらのプロバイダーによって処理されます。

拡張機能は、ライセンスの状態を確認して、Pro 機能のロックを解除する場合があります。

キャプチャしたコンテンツの販売禁止

ArcaWand Soft は、キャプチャしたクリップボードのコンテンツを販売しません。この拡張機能は、個人的な生産性、組織化、およびユーザーによる再利用を目的としています。

ブラウザの権限

この拡張機能は、キャプチャ、ストレージ、クリップボード、インターフェイス、およびオプションの同期ワークフローに必要な権限を要求します。ユーザーは、インストールまたは更新する前に、Chrome で拡張機能の権限を確認できます。

バックアップとエクスポート

ローカル JSON または ZIP エクスポートはユーザーのリクエストに応じて作成されるため、慎重に保存する必要があります。エクスポートされたバックアップにアクセスできる人は誰でも、その内容を読み取ることができる可能性があります。

セキュリティへの期待

ユーザーは、Chrome を常に最新の状態に保ち、オペレーティング システム アカウントを保護し、信頼できない拡張機能を避け、信頼できる場所にバックアップを保存する必要があります。 Vault へのアクセスは偶然の危険を減らしますが、オペレーティング システムのセキュリティに取って代わるものではありません。
