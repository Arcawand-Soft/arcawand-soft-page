プライバシーポリシー

ArcaWand Soft Web サイトが技術データ、連絡先メッセージ、起動通知、分析、外部サービス、およびユーザー権利をどのように処理するか。

このポリシーの範囲

このポリシーは、arcawand-soft.com の公開 ArcaWand Soft Web サイトに適用されます。これには、ArcaWand Soft に関する一般ページ、公開製品プレゼンテーション ページ、連絡先ページ、発売のお知らせ、および情報コンテンツが含まれます。

Product 固有のページには、独自のプライバシー ポリシーがある場合があります。この一般的な Web サイト ポリシーでは、製品やブラウザ拡張機能の内部ストレージ、権限、機能の動作については説明しません。

ウェブサイトを運営しているのは誰ですか

このウェブサイトはArcaWand Softによって運営されています。プライバシーに関する質問、データリクエスト、サポートに関する質問、またはセキュリティに関する懸念については、contact@arcawand-soft.com までお問い合わせください。

訪問時に処理されるデータ

この Web サイトは主に静的な情報サイトであり、訪問者アカウントは必要ありません。ホスティング、セキュリティ、およびパフォーマンス システムは、IP アドレスまたはおおよその位置、ブラウザとデバイスの詳細、要求された URL、リファラー、言語設定、アクセス日時、エラー情報、基本的な対話信号などの技術データを自動的に処理する場合があります。

この情報は、サイトの配信、可用性の維持、悪用の防止、エラーの診断、パフォーマンスの測定、有用なページの理解、およびコンテンツの品質の向上に使用されます。

連絡先メッセージ

電子メールまたは連絡先リンクを通じて ArcaWand Soft に連絡すると、電子メール アドレス、提供された場合は名前、メッセージの内容、件名、添付ファイル、および任意の技術的コンテキストなど、送信することを選択した情報を受け取ります。

当社はこのデータを使用して、対応、サポートの提供、ビジネスや報道機関からの問い合わせの管理、製品フィードバックのフォローアップ、必要に応じたやり取りの合理的な記録の保存を行います。

通知とメールフォームを起動する

一部のページでは、発売や重要なアップデートについての通知を受け取るために、訪問者に電子メール アドレスを残すように勧める場合があります。アクティブな場合、アドレスは指定された通知および直接関連する通信にのみ使用されます。

フォームは、安全なサーバー側のエンドポイントまたは電子メール サービスに依存する場合があります。プライベート API キーとプロバイダー シークレットは、公開 Web サイトのコードで意図的に公開されることはありません。いつでも購読を解除したり、削除をリクエストしたりできます。

分析、Cookie、ローカル ストレージ

このサイトでは、プライバシーを意識した分析、セキュリティ スクリプト、パフォーマンス ツール、またはエラー診断を使用する場合があります。構成に応じて、これらのツールは Cookie、ローカル ストレージ、リクエスト メタデータ、または同様のブラウザ テクノロジを使用する場合があります。

言語設定、インターフェースの選択、または終了状態はブラウザーにローカルに保存されるため、サイトは一貫して動作します。ブラウザの設定から Cookie とサイト データを消去できます。

ホスティングおよび外部サービス

Web サイトは静的サイトとしてホストされており、ホスティング、DNS、CDN、セキュリティ、分析、電子メール配信、フォーム処理、支払いリンク、外部配布ページなどのインフラストラクチャ サービスを使用する場合があります。

これらのプロバイダーは、サービスの提供、サイトの保護、メッセージのルーティング、支払いの処理、パフォーマンスの測定、または法的義務の遵守に必要な場合にのみ、限られたデータを処理します。外部チェックアウト ページ、アプリ ストア、Chrome Web ストア ページ、ソーシャル プラットフォーム、およびサードパーティのリンクには、それぞれ独自のプライバシー ポリシーが適用されます。

目的と法的根拠

お客様の所在地によっては、処理は、Web サイトの運営、保護、改善における正当な利益、オプションの分析やマーケティング コミュニケーションに必要な場合の同意、直接の要求に応じる場合の契約上の必要性、および記録を保存する必要がある場合の法的義務に依存する場合があります。

データ共有

ArcaWand Soft は、Web サイトを通じて収集した個人データを販売しません。限定されたデータは、サイトを介したホスト、セキュリティ保護、分析、操作、通信を支援するサービス プロバイダーと共有される場合や、法令順守、セキュリティ、詐欺防止、または正当な法的要求に必要な場合に共有される場合があります。

保持

技術ログは、セキュリティ、デバッグ、分析、および運用の信頼性に必要な合理的な期間のみ保存されます。連絡先電子メールは、リクエストに応答し、ビジネス記録を維持し、正当な利益を保護するために必要な限り保持されます。通知のサインアップ データは、購読解除、削除リクエスト、またはサービスのクリーンアップまで保持されます。

セキュリティ

このサイトは HTTPS と信頼できるインフラストラクチャ プロバイダーを使用します。絶対的なセキュリティを保証できる公開 Web サイトはありませんが、サイトは可能な限りシンプルかつ静的に保たれており、不必要なデータ収集を避け、フロントエンド コードでプライベート資格情報が公開されることを避けています。

あなたの権利

お住まいの国または地域によっては、データ保護当局にアクセス、修正、削除、制限または処理に対する異議申し立て、同意の撤回、ポータビリティの要求、または苦情を申し立てる権利がある場合があります。

これらの権利を行使するには、contact@arcawand-soft.com までご連絡ください。リクエストを確認して処理するために十分な情報が必要になる場合があります。

子供たち

この Web サイトは子供向けではなく、故意に子供に個人データを要求することはありません。お子様がサイトを通じて個人データを提供したと思われる場合は、当社にご連絡ください。当社が個人データを確認し、必要に応じて削除いたします。

このポリシーの変更

このポリシーは、Web サイト、法的要件、サービスプロバイダー、またはプライバシー慣行が変更された場合に更新されることがあります。このページに公開されている最新バージョンは、公開された日から適用されます。
