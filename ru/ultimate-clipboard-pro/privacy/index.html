Политика конфиденциальностиUltimate Clipboard Pro

Ultimate Clipboard Pro разработан как локальное расширение браузера. На этой странице объясняется, какие данные обрабатываются, где они хранятся, к каким дополнительным службам можно обращаться и как пользователи сохраняют контроль.

Последнее обновление: 13 мая 2026 г.

Обзор

Ultimate Clipboard Pro — это расширение Chrome, созданное ArcaWand Soft, чтобы помочь пользователям захватывать, организовывать, искать, редактировать и повторно использовать текст, код и изображения во время просмотра.

Продукт разработан с учетом философии локального подхода: обычное управление захватом происходит внутри среды расширения браузера на пользовательском устройстве.

Разработчик и контакты

Ultimate Clipboard Pro опубликован ArcaWand Soft. По вопросам конфиденциальности, поддержки или вопросов соответствия требованиям Chrome Интернет-магазина обращайтесь по адресу contact@arcawand-soft.com.

Chrome Обязательство данных пользователей интернет-магазина

Эта политика предназначена для обеспечения соответствия поведению расширения и раскрытию информации о конфиденциальности, представленной на панели инструментов разработчика интернет-магазина Chrome. Если раскрытие информации, разрешение или функция изменятся, эту политику следует соответствующим образом обновить.

Расширение использует запрошенные разрешения только для предоставления или улучшения четко описанных функций продукта. Он не использует разрешения для сбора несвязанных данных о просмотре.

Заявление об ограниченном использовании Google API

Если пользователь включает синхронизацию Google Drive, расширение может получать информацию от API Google для создания, чтения, обновления или восстановления файлов резервных копий Ultimate Clipboard Pro пользователя.

Использование и передача информации, полученной от API Google, будет осуществляться в соответствии с Политикой пользовательских данных интернет-магазина Chrome, включая требования ограниченного использования. Данные Google API используются только для предоставления пользователям функций резервного копирования и синхронизации, не продаются и не используются для рекламы.

Подробные категории данных

Предоставляемый пользователем контент может включать захваченный текст, код, изображения, снимки экрана, заметки, написанные вручную заголовки, категории и монтажный контент.

Метаданные источника и использования могут включать заголовок страницы, URL-адрес источника, значок значка, дату захвата, дату создания версии, избранное, закрепленное состояние, состояние корзины, состояние хранилища, настройки отображения, язык, тему, цвет акцента и другие настройки, выбранные пользователем.

Статус лицензии и платежа может включать минимальную информацию, необходимую для проверки доступа к Pro через выбранного поставщика лицензий или платежей. ArcaWand Soft не обрабатывает номера карт внутри расширения.

Цели обработки

Данные обрабатываются для сохранения снимков, их отображения в расширении, организации их по рабочей области и категории, поиска, создания версий, восстановления удаленных снимков, копирования снимков обратно в буфер обмена, экспорта резервных копий, синхронизации дополнительных резервных копий на Диске и применения ограничений Pro или доступа.

Совместное использование и сторонние сервисы

Захваченный контент не передается ArcaWand Soft для обычного локального использования.

К дополнительным сторонним службам можно обращаться только при необходимости: Google Drive для синхронизации с поддержкой пользователей, поставщики платежей или лицензий для активации Pro и базовая аналитика веб-сайта для общедоступного маркетингового сайта.

Безопасность и передача

Данные локального расширения остаются в среде расширения браузера, пока пользователь не экспортирует их, не скопирует, не включит синхронизацию с Диском или не использует другую явную функцию для перемещения данных.

Если для дополнительных услуг требуется сетевое соединение, следует использовать HTTPS или безопасный транспорт, предоставляемый браузером и соответствующим провайдером.

Хранение, удаление и контроль пользователей

Пользователи могут удалять снимки внутри расширения, очищать корзину, если она доступна, экспортировать локальные резервные копии, восстанавливать резервные копии, отключать синхронизацию Диска и удалять расширение из Chrome.

Удаление расширения или очистка хранилища расширений Chrome могут привести к удалению локальных данных. Данные, хранящиеся в Google Drive, остаются в учетной записи Google пользователя до тех пор, пока пользователь не удалит их оттуда.

Дети и деликатный контент

Ultimate Clipboard Pro — это инструмент повышения производительности для обычных пользователей, который не предназначен для детей. Пользователям следует избегать хранения конфиденциальных секретов, если они не понимают модель безопасности своего устройства, браузера и резервного копирования.

Международное использование

Расширение и веб-сайт можно использовать на международном уровне. Поставщики дополнительных услуг могут обрабатывать технические данные в странах, где они работают, в соответствии со своими собственными условиями и политикой конфиденциальности.

Обновления политики

Эта политика конфиденциальности может быть обновлена, чтобы отразить изменения в продукте, законодательстве, интернет-магазине Chrome или поставщике. Дата, указанная на этой странице, указывает на последнее опубликованное обновление.

Данные, обрабатываемые расширением

В зависимости от используемых функций расширение может хранить захваченный текст, код, данные изображений, снимки экрана, метаданные страниц, заголовки, заметки, категории, избранное, закрепленные состояния, исходные URL-адреса, значки, историю версий, настройки отображения и пользовательские настройки.

Локальное хранилище

По умолчанию захваченный контент и настройки сохраняются локально в хранилище расширений браузера. Удаление расширения или очистка данных расширения браузера может привести к удалению локальных снимков, если только пользователь не экспортировал или не синхронизировал резервную копию.

Дополнительная синхронизация Google Drive

Если пользователь подключает Google Drive, расширение может создать или обновить папку Ultimate Clipboard Pro в учетной записи пользователя на Диске для резервного копирования и восстановления данных расширения.

Синхронизация Google Drive не является обязательной и контролируется пользователем.

Платежи и лицензирование

В потоках лицензирования и платежей Pro могут использоваться сторонние поставщики платежей и лицензий. Платежные реквизиты обрабатываются этими поставщиками, а не общедоступной базой данных ArcaWand Soft.

Расширение может проверять состояние лицензии, чтобы разблокировать функциональность Pro.

Запрещена продажа захваченного контента

ArcaWand Soft не продает захваченное содержимое буфера обмена. Расширение предназначено для приватной продуктивности, организации и повторного использования пользователем.

Разрешения браузера

Расширение запрашивает разрешения, необходимые для захвата, хранения, буфера обмена, интерфейса и дополнительных рабочих процессов синхронизации. Пользователи могут просмотреть разрешения расширения в Chrome перед установкой или обновлением.

Резервные копии и экспорт

Локальные экспортированные данные в формате JSON или ZIP создаются по запросу пользователя и должны храниться с осторожностью. Любой, у кого есть доступ к экспортированной резервной копии, может прочитать ее содержимое.

Ожидания безопасности

Пользователи должны обновлять Chrome, защищать свою учетную запись операционной системы, избегать ненадежных расширений и хранить резервные копии в надежных местах. Доступ к хранилищу снижает случайное воздействие, но не заменяет безопасность операционной системы.
