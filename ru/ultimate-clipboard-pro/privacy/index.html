05Расширение не содержит рекламы, таргетинга рекламы, поведенческого профилирования или аналитики разработчиков

06Разрешения Chrome используются только для видимых функций продукта

Разрешения Chrome используются только для видимых функций продукта: захват на поддерживаемых страницах, чтение и запись в буфере обмена, запускаемые пользователем, локальное хранилище, контекстные меню, представления расширений, действия на активной вкладке, снимки экрана, локальное распознавание символов, размещение с учетом монитора, локальный импорт/экспорт ZIP, а также синхронизация учетных данных Google и файлов Диска только тогда, когда пользователь включает эту функцию.

07Пользователь управляет сохраненными данными

Пользователь управляет сохраненными данными. Элементы можно редактировать, давать названия, версии, удалять, классифицировать, перетаскивать, перемещать, защищать в Vault, экспортировать в резервную копию ZIP, восстанавливать из локальных файлов, синхронизировать с Диском, когда включен Pro, или удалять путем очистки хранилища расширений.

08Dodo Payments выступает в качестве зарегистрированного продавца для оформления заказа Pro и обрабатывает платежи, применимые налоги на транзакции и платежную документацию на своих собственных условиях

Dodo Payments выступает в качестве зарегистрированного продавца для оформления заказа Pro и обрабатывает платежи, применимые налоги на транзакции и платежную документацию на своих собственных условиях. Расширение взаимодействует со специальной службой лицензирования Arcawand Soft для выполнения лицензионных операций; этот сервис проверяет коммерческое право с Dodo. Ни один поток не получает захваченный контент или резервные копии Диска.

09Обмен между устройствами выполняется только через аккаунт Google Drive, явно подключённый пользователем

Обмен между устройствами выполняется только через аккаунт Google Drive, явно подключённый пользователем. Обычные тексты, код и изображения синхронизируются; содержимое Vault остаётся локальным и никогда не синхронизируется.

10область действия файла

область действия файла. Электронная почта идентифицирует подключенное рабочее пространство. Данные регулярного резервного копирования передаются напрямую между расширением и Google Диском для синхронизации и восстановления; Содержимое хранилища исключено. Arcawand Soft и Dodo Payments не получают файлы с Диска и содержимое буфера обмена.

11Данные лицензии

Данные лицензии: только когда пользователь проверяет, активирует, восстанавливает, обновляет или удаляет лицензию Pro, расширение связывается со специальной службой лицензий Arcawand Soft. Активация или проверка могут передать введенный лицензионный ключ; при обычной авторизации используются подписанные возобновляемые токены. Сервис обрабатывает псевдонимные идентификаторы установки и лицензии, приблизительную метку устройства, версию клиента и технические события безопасности, а также проверяет коммерческие полномочия с помощью Dodo Payments. Он никогда не получает снимки, результаты поиска, данные Хранилища или резервные копии Диска.

12Хранение и удаление

Хранение и удаление: локальные записи и настройки сохраняются до тех пор, пока пользователь не удалит их, не очистит данные расширения или не удалит расширение. Локальные резервные копии ZIP остаются там, где их сохраняет пользователь; Резервные копии диска остаются на Диске пользователя до тех пор, пока не будут удалены оттуда. Записи о лицензиях сохраняются до тех пор, пока они необходимы для эксплуатации, защиты, отзыва и документирования лицензии или для выполнения юридических обязательств; удаление лицензии приводит к удаленной деактивации устройства до удаления локальной авторизации, когда услуга становится доступной.

13Безопасность

Безопасность: лицензионные ключи не сохраняются как обычные долгосрочные настройки. Токены авторизации имеют криптографическую подпись и привязаны к устройству; Конфиденциальные лицензионные материалы на стороне сервера шифруются или хешируются, а в технических журналах секреты удаляются. Токены Google OAuth обрабатываются API-интерфейсами идентификации Chrome. Ни одна система не может гарантировать абсолютную безопасность, поэтому пользователи должны защищать свой профиль Chrome, учетную запись Диска, экспортированные резервные копии и пароль хранилища.

14Ultimate Clipboard Pro соответствует Политике пользовательских данных Интернет-магазина Chrome

Ultimate Clipboard Pro соответствует Политике пользовательских данных Интернет-магазина Chrome. Его использование и передача информации, полученной от API Google, также соответствует Политике использования данных пользователей служб API Google, включая требования ограниченного использования. Пользовательские данные Google используются только для обеспечения возможности подключения к Диску, синхронизации и восстановления функций, запрошенных пользователем; он не используется для рекламы, принятия кредитных решений, профилирования или других целей и не читается людьми, за исключением случаев, когда это требуется для обеспечения безопасности, соблюдения законодательства или поддержки, запрошенной пользователем с явного согласия.

15Публичный веб-сайт Arcawand Soft отделен от расширения

Публичный веб-сайт Arcawand Soft отделен от расширения. Расширение не содержит аналитики разработчиков. Измерение веб-сайта, если оно принято через элементы управления согласием на сайте, касается посещений общедоступного веб-сайта и не учитывает данные расширений, историю буфера обмена, содержимое Сейфа, резервные копии на Диске или поиск расширений.
